# 方法源码阅读入口

本目录选取四份实验中的自有源码，帮助审阅模型结构、输入隐藏规则、空间基线和指标定义。文件保留已验收版本的原始内容，没有为公开展示改写计算逻辑。

这是**可审阅的源码快照**，不是可直接训练或完整复现实验的一键工程。目录不包含原始数据、预处理产物、模型权重、训练调度或云连接入口，也未附带第三方完整仓库。公开可读不代表已授予某种开源许可证；本仓库未添加公开许可证。

| 文件 | 建议关注的部分 |
|---|---|
| [models.py](models.py) | 小型 U-Net：三次下采样、GroupNorm、双线性上采样、两个目标输出 |
| [context.py](context.py) | 全局网格对齐的棋盘隐藏、整块白格保留、角色内代理组同步隐藏，以及 143 通道输入的构造 |
| [spatial.py](spatial.py) | 按可见面积归一化的高斯核密度，以及十种矿产的 64 维固定空间特征 |
| [metrics.py](metrics.py) | AP 并列分数处理、面积预算、代理组命中和面积排序的固定并列规则 |

## 与实验的对应关系

本轮稳健性实验复用先前训练的三个仅矿产网络，没有重新训练神经网络。`models.py` 中关于初始化的注释描述模型定义的来源，不表示本轮又进行了新拟合。

`context.py` 构造 `143 × 50 × 50` 输入：前 131 个地质特征通道置零；第 132 个通道保留有效范围；随后十个通道为当前可见矿产；最后一个通道为可见性标记。输入中没有出现矿点的格子，与矿产输入被隐藏的格子，通过可见性标记区分。

50% 与 25% 保留情景按固定哈希选择整块白格；同一重复下 25% 保留集包含在 50% 保留集中。先在整个训练、验证或评价角色范围内同步处理代理组，再切出模型图块。被隐藏记录所带的其他矿种信息也同步去掉。距离只从当前图块内保留下来的记录计算。

`spatial.py` 的核密度以可见矿产网格为计数对象，并除以经过同一核加权的实际可见面积。核带宽候选为 2、5、10、20 km，主带宽 5 km 由验证域一次选择。固定空间特征包含每种矿产的距离、存在标记与四个带宽的密度，以及四个可见面积支持比例；随机森林训练流程不在本目录中。

## 依赖与缺省的数据接口

- `models.py` 依赖 PyTorch；`spatial.py` 依赖 NumPy 和 SciPy；`metrics.py` 依赖 NumPy，其内置小型自检另外使用 scikit-learn。
- `context.py` 依赖 NumPy、SciPy，并导入实验数据接口 `checker.Data`、`checker.black`、`checker.grid` 与 `common.digest_arrays`。这些接口及其数据文件未包含在本公开快照中，因此直接导入该文件会缺少依赖。这一限制是公开范围的说明，不是完整复现已经完成的声明。
- 数据接口需要提供 2 km 网格坐标、有效范围、实际面积、十种矿产的记录到网格关系、代理组关系及已固定的空间角色。上述接口决定信息隔离，不能用随意构造的替代数据来声称复现真实实验。

结果字段、平均顺序和差值方向见 [结果表说明](../results/README.md)。原始冻结源码与完整运行证据保留在本地复核归档中。
