# cap3 覆盖与验证选择聚合材料

2026-10-12，`reduced_cap3_v1`。正式拟合完成、正式评价未执行。验证集用于选择检查点；本目录不包含正式评价区 AP、预测网格、记录身份、模型权重或日志。

| 文件 | 内容 |
|---|---|
| [NN_validation.csv](NN_validation.csv) | 15 行模型级验证 AP：五输入组×三个种子，含金铜 AP、最佳步数与结束步数 |
| [R_role_coverage.csv](R_role_coverage.csv) | 五分区相同原面积分母下的 cap2/cap3 达标面积及未舍入比例 |
| [summary.json](summary.json) | 均值、三种子样本标准差、拟合计数、评价状态和解释边界 |
| [provenance.json](provenance.json) | 选用来源记录及公开聚合附件的 SHA256 和字节数 |

在仓库根目录运行 `python analysis/check_cap3_validation.py`，独立从15行聚合数值复算金铜等权 AP、三种子均值/样本标准差、配对方向，并核对面积分母和80%门槛、附件哈希及专题表格舍入。采用绝对容差1e-12，不读取实验模块、训练或推理。没有重算逐格 AP、原始影像或地质真值；标准差不是置信区间。

验证为固定6块、13,943个原有效格、L10两相位、完整白块上下文。不是预设L10/25%正式主比较；不与9月不同支持的成绩相减。来源记录正文、备份包和原始/处理数据继续保留本地。
