# cap3正式评价聚合材料

2026-10-14，`reduced_cap3_v1`。使用既有冻结模型完成CPU正式评价，无新增训练。此目录只含地区×矿种×模型×固定情景级指标，未包含逐格预测、身份映射、权重或日志。

| 文件 | 内容 |
|---|---|
| [main_metrics.csv](main_metrics.csv) | 2112行合并两相位后的模型级指标；列为架构、输入、种子、尺度、上下文重复、地区、目标、AP及面积覆盖等 |
| [comparisons.csv](comparisons.csv) | 96个架构/输入/尺度/上下文组合的等权汇总 |
| [scientific_summary.json](scientific_summary.json) | 预设主比较、地区/种子方向、继续判据、支持分母、已执行计数与归档限制 |
| [provenance.json](provenance.json) | 来源及公开CSV/摘要/两幅自有聚合图的SHA256；图件为原字节复制 |

两相位在原科学评价中先合并；本公开表不能重新构造逐格AP。UNet种子17/29/43；RF固定731；确定性基线种子为空。50%/25%使用重复101/211/307，100%/0%使用重复0。每个情景三区各7500原有效格；种子及复用网格不是独立地质样本。

运行 `python analysis/check_cap3_formal.py` 从2112行重新汇总均值，核对54项主配对、相对AP差、覆盖百分点、地区/种子方向和固定继续判据，核对96组汇总、文档舍入与附件哈希。绝对容差1e-12，原检查规则保持。它不加载模型，不读取预测数组，不执行新的独立科学评价。报告中的27456行预测指标复算和55重载检查属于已有研究复核。
