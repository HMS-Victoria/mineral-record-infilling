# Cuprite岩性准备：吸收输入与相对配准通过，完整标签尚未准入

更新：2026年10月18日。最新准备交付已验收，但**新岩性监督尚未准入，监督拟合0、评价0，无四组模型成绩**。它与已完成的历史蚀变覆盖率CPU对照是不同目标，不能互相填补结果。当前停止点是标签质量和空间支持未建立，不是算力不足或模型已跑输。

## 从早期可行性到当前成果

早期取得35份样品描述，24条单点坐标去重为23个ID，当时东带与航磁共同区有7个历史XRD样品名义位置；后续两带记录扩展为14个唯一样品ID。它们是选择性历史样品，包含混合物、包膜和分离物，不是互斥类别、2020逐像元真值或足量独立监督集。早期62/12个400/800 m候选格没有扣标签与缓冲，不能与后续78个完整开发格混为同一筛选口径。

Cuprite4已取得并核验，两条2020-07-12航带各有425波段、372个好波段、2.9 m像元；原图合计9,014,324,800字节。NAD27转换所需格网已补齐，当前坐标操作标称2.15 m，较旧回退方案位移约0.6—0.74 m；这不是整体绝对定位精度。早期约80 m是忽略基准转换的偏差，二者也不是同一量。

独立NAIP参考的20个固定窗19通过已有记录，支持相对定位检查；绝对HSI地面精度、跨带辐射一致性与同期密集真值仍未验收。早期可行性核查的验收文件现已存在，证明该阶段交付完整，不等于科学训练获准。

## 吸收工程检查实际证明什么

四个搜索区间固定为2155–2180、2190–2225、2295–2335、2335–2365 nm；固定肩部均值建立直线连续谱，取最大有符号深度，先逐像元提取再按完整400 m格相交面积汇总。没有用目标面裁剪光谱，没有峰位、宽度、矿物类别或丰度输出。负深度不解释为负含量。

两族高分辨核心参考在SNR200模拟噪声下最大P95深度误差约0.0109/0.0101，肩点±5 nm最大变化约0.0424/0.0075，分别低于事先0.03/0.05门槛。模拟SNR不是实测影像噪声；没有实测响应曲线，采用FWHM高斯近似，不跨缺口插值、不把粗库谱重采样当作更高真实分辨率。高岭石、明矾石、混合谱和2.3μm不同组分的响应可重叠，不能单峰判矿物。

已有独立数值检查重算588卷积通道、46深度标量及4个预定端点格的32特征；最大差约1.26×10⁻⁶、0及1.11×10⁻¹⁶。后者不是全部78格独立重做。本次维护核对来源绑定、摘要算术与准入状态，没有重解9GB影像、读取逐格S或执行新模型。

## 标签为何仍不能开跑

两图分别仿射，使用预写的至少8控制＋4留出、RMSE≤100 m/最大≤200 m工程门槛，实际误差均通过；相对配准与整格岩性标签可靠是两件事。Long署名更早且不同，但原始方法来源未找到，不能宣称调查完全独立；1980岩性与旧蚀变属于同一历史调查体系。

扩大原图上下文后，Long四个位置、Plate1一个位置可作单元内部候选，另九个“位置×来源”值得继续描图，不能说地图完全无用。真正缺项是完整原码面的拓扑、known/unknown面积和适用空间支持。Plate1图面有TQoa但13码候选图例未映射；Long局部本身有Ch?/Ce?疑问，不强制补码、拼两图或把未分类部分当背景。

一个Trp候选面积25,838.29 m²，只占其400 m格16.15%；面外尚未分类。50 m示例内缩仅剩3,724.08 m²，100 m为空；这是单个小面的边界诊断，不是全图最终未知带。**每类独立源面数、空间块支持与准入格数尚未确定，不能写成实测0，也不能据24条抽查认定全部78格不可用。** 原图AI判读不是地质专家或现场验收。

1. 优先建立单一历史来源的原码面并做第二人独立复描；保留疑问、遮挡和来源关系，不能跨图挑易读部分拼真值。
2. 冻结未知带、known/unknown面积和共同集合，整格分母160,000 m²；按独立源面及连续空间块确定支持，不将已知部分归一化成整格或直接复制旧11折。
3. 标签和空间协议通过后，才比较H、S、H+M、S+M及均值/坐标诊断；S和配准可复用。若不能形成可复核支持，结束这个训练目标，保留准备成果。
