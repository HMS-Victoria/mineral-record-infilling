# 结果复核与公开范围

更新：2026 年 10 月 15 日。本页区分可以在公开仓库核对的内容与保存在本地的完整实验材料。

## 公开仓库可以做什么

- 阅读实验定义、主要结果与局限。
- 使用 `results/` 中的聚合 CSV 核对报告均值、方法差值及上下文变化。
- 查看 22 张原实验图（包括预先固定的三个案例），以及新增的五分区遥感覆盖图。
- 审阅 `methods/` 中 U-Net、遮蔽、空间基线和指标的精选源码。

仅用 Python 3 标准库，在仓库根目录运行：

```text
python analysis/summarize.py
```

脚本从 576 行主指标表开始，核对完整上下文四种方法和 50% / 25% 条件的均值，再与保存的 `summary.json` 比较。它不导入原实验模块，不训练、不推理、不下载数据。它能够验证公开表之间的算术一致性，**不能从聚合表重新计算逐网格 AP**。

原始与处理后数据、空间划分、记录分组、冻结配置、权重、逐次预测、运行日志和完整复核包保留在原研究归档中。公开目录是单独整理的汇报副本；原冻结实验未因公开整理而修改。

9月稳健性轮包括 192 份相位预测、576 行主指标和 2,880 行距离分段指标。另写的计算路径已从保存预测复算主指标、相位指标、距离指标与配对汇总，并核查评分支持、输入隐藏与哈希一致性。此类数值和设计核对提高可检查性，但不是新的模型实验，也不是外部同行评审或独立地质验证。

## 精选源码的边界

`methods/` 保留原实现字节，便于理解报告中的方法。它不是独立安装包，其中遮蔽实现依赖未公开的数据接口；仓库没有提供完整数据流水线、训练入口和模型权重。因此不能仅凭这些文件重新训练并复现全部实验。详见[源码说明](../methods/README.md)。
